Interoperable Data Control

JLINC uses some of the same tech puzzle pieces that made blockchain possible â in a totally new way.

Cryptographic keys and hashes are used to sign human-readable, and therefore legally admissible, contracts exchanged between cloud agents representing each party.

Audit proof can be written to any database, log, ledger or blockchain.

JLINC is an agent-based API protocol that provides scalable solutions.

Contract-based data exchange provides a safe way for each party to share data with others under an automated system. Data usage can be governed by standard framework agreements that no party can unilaterally change.

From a technical perspective, this is based on a "cloud agent" paradigm. Each party has an agent that operates as their representative in data relationships. Each organization has an agent that can be operated as a cloud service or behind their firewall on their own server. When an individual chooses to share data with an organization, they can do it in one click using a profile, and they can do it in a way that is digitally signed, auditable, verifiable and secure.

The system is decentralized and interoperable without requiring any blockchain or token. It's a new internet paradigm that actually serves all parties' interests.

Why JLINC?

Reduce Data Risk

Significant business risk arises from not having a clear view of data, what came in, from where, for what purpose, and on what terms, and most importantly, where did it then go from here. JLINC enables the automated logging of data lineage and provenance with permissions, which allows data risk to be actively managed.

Demonstrate Compliance

Compliance with many of today's regulations require an audit trail that shows exactly how that data has been derived. JLINC automates this process by logging every data transaction, categorizing it and making that validation available for all relevant parties to inspect should they want or need to do so.
