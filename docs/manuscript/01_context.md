# Scope

The Links repository implements a staged document workflow [@links]. This note examines the first stage, where metadata enters the workflow as an ordered JSON array. At this boundary, a local experiment can distinguish what the organizer does to the input from changes introduced by later collection, extraction, and document generation.

The inputs in this experiment are authored examples about museum objects and use the reserved example.org domain [@rfc2606]. The organizer reads those domain names as strings. The fixture and observations concern the local metadata contract.
